# 十一康复陪伴网站设计文档

**日期**：2026-09-07
**手术日期**：2026-09-09
**主题**：髌骨脱位术后康复陪伴网站

## 一、项目背景与目标

十一将于 2026年9月9日做髌骨脱位手术。本项目为十一打造一个温馨的康复陪伴网站，帮助她：

1. 每日康复训练打卡，跟踪恢复进度
2. 缓解焦虑情绪，记录心情变化
3. 看到朋友家人的鼓励留言，获得情感支持
4. 清晰了解自己所处的康复阶段与接下来要做的

**核心用户**：十一（主用户，需要访问码）
**访问用户**：十一的朋友家人（无需登录，可查看进度并留言）

**设计原则**：
- 移动优先（十一日常以手机访问为主）
- 可爱治愈风格，以布偶猫为主题（十一养了一只布偶猫）
- 所有康复动作居家可完成
- 轻量级，避免过度工程

## 二、架构与技术栈

### 技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | Next.js 14 (App Router) | 全栈框架 |
| 语言 | TypeScript | 类型安全 |

| 测试 | Vitest + Testing Library | 轻量单元测试 |

### 访问码鉴权机制

- 环境变量 `OWNER_CODE` 存储主人访问码
- 十一输入正确访问码 → 设置 httpOnly cookie（7天有效期）
- 朋友访问公开页面（首页、留言墙）无需码
- 朋友无需注册账号，直接填昵称+内容留言

## 三、数据模型

```prisma
// 康复动作定义（预设数据，可后续修改）
model RehabExercise {
  id          String   @id @default(cuid())
  phase       String   // "pre" | "early" | "mid" | "late"
  name        String   // 动作名称
  description String   // 动作描述
  targetReps  Int      // 目标次数/组数
  unit        String   // "次" | "组" | "秒" | "分钟"
  category    String   // "exercise" | "scar" | "care"
  order       Int      // 显示顺序
}

// 每日打卡记录
model RehabLog {
  id            String   @id @default(cuid())
  date          String   // "2026-09-10" 本地日期字符串
  exerciseName  String   // 动作名（不外键，保留历史）
  completedReps Int      // 实际完成次数
  done          Boolean // 是否完成
  note          String?  // 备注（疼痛感等）
  createdAt     DateTime @default(now())
}

// 朋友留言
model Message {
  id        String   @id @default(cuid())
  name      String   // 留言者昵称
  content   String   // 留言内容
  emoji     String?  // 选择的表情
  createdAt DateTime @default(now())
}

// 情绪记录（十一专用）
model MoodLog {
  id        String   @id @default(cuid())
  date      String   // "2026-09-10"
  mood      String   // "great" | "good" | "ok" | "down" | "anxious"
  note      String?  // 想说的话
  createdAt DateTime @default(now())
}
```

**设计要点：**
- 日期用字符串 `"YYYY-MM-DD"` 而非 DateTime，避免时区问题
- `RehabLog` 不用外键关联 `RehabExercise`，动作定义修改不影响历史记录
- 留言不绑定用户账号，直接填昵称即可
- 情绪记录只有十一能看，需访问码

## 四、页面与功能

### 公开页面（朋友可访问，无需码）

#### 1. 首页 `/`
- 顶部：布偶猫吉祥物 + 标题"十一的康复小窝"
- 核心卡片：手术后天数大字显示（术前显示倒计时）
- 康复进度条：当前阶段 + 总体进度百分比
- 今日心情卡片（十一记录的，朋友可见）
- 底部 CTA："给十一留句鼓励 →" 跳转留言墙

#### 2. 留言墙 `/wall`
- 顶部：可爱的布偶猫插画
- 留言列表：卡片纵向瀑布流，显示昵称、内容、表情、时间
- 底部：留言表单（昵称输入框 + 内容输入框 + emoji 选择器）
- 手机大输入框，提交后即时刷新显示

### 十一专属页面（需访问码）

#### 3. 登录页 `/login`
- 布偶猫 + 输入框："请输入访问码"
- 输入正确 → 设 cookie 跳转打卡页
- 输入错误 → 提示"访问码不正确"

#### 4. 康复打卡页 `/rehab`
- 顶部日期 + 当天阶段标签
- 动作卡片列表，每张卡片包含：
  - 动作名 + 描述
  - 目标次数
  - 实际完成数输入
  - 打卡按钮
- 疤痕护理卡片（每天常规任务，含硅酮凝胶、减张胶带、疤痕按摩等）
- 完成后卡片变色 + 猫咪庆祝动画
- 底部统计：今日完成 X/Y 项

#### 5. 情绪记录页 `/mood`
- 5 个情绪选项大按钮（emoji 表示）
- 可选文字记录
- 历史情绪曲线（最近 7 天）

#### 6. 时间线页 `/timeline`
- 手术日期（2026-09-09）为锚点
- 各阶段时间轴：术前 → 早期 → 中期 → 后期
- 每个阶段下显示该阶段动作清单
- 打卡记录历史展示

### 通用组件
- `CatMascot`：布偶猫吉祥物，不同页面不同表情（加油、庆祝、安慰、休息）
- `BottomNav`：底部导航栏（手机友好），十一页面有 4 个 tab：打卡/心情/时间线/留言墙

## 五、康复方案内容

基于髌骨脱位术后通用康复方案，**全部居家可完成**。用户后续可自行修改。

### 术前阶段（现在 ~ 2026-09-09）

| 动作 | 目标 | 说明 |
|------|------|------|
| 术前心理准备 | 1 次 | 了解流程，减少焦虑 |
| 踝泵运动 | 50 次 | 促循环，防血栓 |
| 股四头肌等长收缩 | 20 次 | 维持肌力 |
| 患肢抬高 | 15 分钟 | 减轻肿胀 |

### 术后早期（2026-09-10 ~ 第 2 周）

| 动作 | 目标 | 说明 |
|------|------|------|
| 踝泵运动 | 100 次/天 | 防血栓、消肿胀 |
| 股四头肌等长收缩 | 30 次 × 3 组 | 维持肌力 |
| 腘绳肌等长收缩 | 20 次 × 3 组 | 后侧肌群维持 |
| 直腿抬高（SLR） | 15 次 × 3 组 | 不负重练肌力 |
| 冰敷 | 3 次/天 | 15-20 分钟/次，消肿 |
| 患肢抬高 | 4 次/天 | 高于心脏 |
| 疤痕护理 - 硅酮凝胶 | 2 次/天 | 伤口愈合后开始 |
| 疤痕护理 - 减张胶带 | 1 次/天 | 减小张力，防疤痕增生 |

### 术后中期（第 3 ~ 6 周）

| 动作 | 目标 | 说明 |
|------|------|------|
| 屈膝活动度训练 | 90° → 渐进 | 坐位/卧位屈膝 |
| 主动直腿抬高 | 20 次 × 3 组 | 强化股四头肌 |
| 侧抬腿 | 15 次 × 3 组 | 臀中肌训练 |
| 靠墙静蹲 | 30 秒 × 3 组 | 渐进负重 |
| 单脚站立平衡 | 30 秒 × 2 组 | 本体感觉训练 |
| 疤痕按摩 | 5 分钟 × 2 次 | 促进疤痕软化 |
| 持续减张护理 | 全天 | 胶带或减张器 |

### 术后后期（第 7 周起）

| 动作 | 目标 | 说明 |
|------|------|------|
| 全屈膝训练 | 至正常范围 | 跪坐等 |
| 弓步训练 | 10 次 × 3 组 | 功能性训练 |
| 上下台阶 | 15 次 × 3 组 | 日常生活功能 |
| 坐姿伸膝（无重量） | 15 次 × 3 组 | 坐椅子缓慢伸直膝盖 |
| 卧位屈膝滑动 | 15 次 × 3 组 | 床上滑动屈膝，改善活动度 |
| 平衡板训练 | 5 分钟 | 进阶本体感觉 |
| 疤痕修复评估 | 每周 1 次 | 观察恢复情况 |

### 每日鼓励语
- 预设 30+ 句鼓励语池，每日随机展示
- 配合布偶猫不同表情

### 情绪选项
- � 棒极了 (great)
- � 还不错 (good)
- � 还行 (ok)
- 🙀 有点糟 (down)
- 😿 焦虑了 (anxious)

## 六、视觉设计（布偶猫主题）

### 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 奶油白 | `#FFF8F0` |
| 卡片背景 | 浅杏 | `#FFE5D9` |
| 强调 | 暖棕（布偶猫重点色） | `#C9886B` |
| 文字 | 深棕 | `#5C4033` |
| 打卡完成 | 薄荷绿 | `#B5E8C9` |
| 鼓励元素 | 粉橘 | `#FFB6A3` |

### 布偶猫元素
- SVG 绘制简洁布偶猫吉祥物（圆脸、蓝眼、重点色耳朵和尾巴）
- 不同情绪/场景的猫咪变体：加油、庆祝、安慰、休息
- 页面点缀：猫爪印图案、毛线球装饰

### 移动端交互
- 大按钮（最小 44px 高，方便点击）
- 卡片纵向堆叠，无需横滑
- 底部导航栏固定，拇指可达
- 打卡用点击而非悬停
- 完成动作时有轻微动画（猫咪弹跳、撒花）

### 字体
- 中文系统字体（iOS 苹方 / Android 思源黑体）
- 标题加粗，正文常规

## 七、错误处理

- API 路由用 try-catch，失败返回 `{ error: "操作失败，请重试" }`
- 数据库连接失败显示友好提示（布偶猫 + 安慰语），不暴露技术错误
- 访问码验证失败：提示"访问码不正确"，不暴露是否存在
- 留言提交失败：保留输入内容，提示重试
- 打卡提交失败：本地暂存，恢复后重试

## 八、测试范围

### 包含
- 单元测试：康复阶段判定逻辑（根据手术日期算阶段）、访问码验证
- API 测试：留言 CRUD、打卡记录读写
- 关键流程手动测试：登录→打卡→查看时间线、朋友留言→墙显示

### 不包含（YAGNI）
- E2E 全流程测试
- 性能测试
- 视觉回归测试
